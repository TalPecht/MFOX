# MFOX v1.4.5 — Navigation + visual discovery workspace

## Changes

- Desktop application navigation moved from a horizontal top navbar to a persistent left navigation rail; mobile keeps the Bootstrap top-navigation behavior.
- Explore and Companies filter sidebars reduced to 220 px to prioritize the evidence/detail workspace.
- Company directory is now the first Companies tab.
- Company Evidence & maturity changed from a wide DataTable to visual cards with MFOX-generated identity marks plus development/evidence icons.
- Community Collaboration groups now uses the same directory-card design with institution identity marks, location, publication/researcher metrics and expandable representative publications.
- Explore Evidence now includes a filtered Sankey-style connection map: sample material → technology → studies → papers/datasets/projects/institutions/companies.
- Study Planner workspace now uses independent left/right columns so short panels do not create blank row space.
- Study Intelligence metrics are forced into one horizontal row; smaller widths use horizontal scrolling.
- Removed the duplicated `uiOutput("plan_summary")` present in the prior build.

## Visual identity marks

MFOX uses locally generated monogram identity marks for companies and collaboration groups rather than fetching external corporate/institutional logo assets. This keeps the app self-contained and avoids broken remote assets while still providing a strong visual anchor.

## Evidence-flow interpretation

The Explore connection graphic is descriptive. Link widths represent counts of linked curated records at each step; they are not evidence-quality scores and should not be interpreted as causal or quantitative biological flows.
