# MFOX v1.4.6 — Data-first layout fix

This release is a focused interface-density and navigation fix built directly from v1.4.5. It does not change the scientific database.

## Main changes

- Fixes the desktop left navigation so it no longer overlays the page. The navigation remains fixed, but the actual bslib page content container receives the horizontal offset and calculated remaining width.
- Sets `page_navbar(fillable = FALSE)` so evidence-heavy pages scroll naturally and fixed-height plots/cards are not compressed by fill layout.
- Removes the nested filter sidebars from **Explore** and **Companies**. Filters now sit in compact horizontal multi-column bars above the evidence canvas.
- Compresses descriptive page headers, purpose cards, summary metrics and helper text so they use substantially less vertical space.
- Expands the main evidence canvases:
  - Explore evidence-flow map: 520 px high
  - Landscape visualization: 820 px high
  - Community scientific-connections plot: 760 px high
  - Community geography map: 720 px high
- Narrows the Landscape filter rail and reduces workspace/card padding.
- Keeps all Study Intelligence tiles in one row while making the planner query/header region more compact.
- Preserves all v1.4.5 company-directory, collaboration-group, connected-evidence and company-overlap functionality.

## Responsive behavior

- Desktop (>= 992 px): persistent 196 px left navigation and full-width evidence content in the remaining viewport.
- Medium screens: filters reflow to two or three columns.
- Mobile: standard top navigation, single-column filters, no left offset.
