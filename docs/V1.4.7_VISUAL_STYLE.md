# MFOX v1.4.7 — Scientific editorial style refresh

This release is a visual-system pass built directly on v1.4.6. It does not change scientific records, evidence links, company curation, or study-planning logic.

## Direction
MFOX now follows a more consistent **scientific editorial** language: warm ivory canvas, wine/rose identity accents, restrained shadows, clearer data-table hierarchy, and less generic dashboard chrome.

## Changes
- Enlarged MFOX logo and strengthened brand treatment in the desktop side rail.
- Preserved the v1.4.6 data-first page offsets and wide evidence canvases.
- Added clearer active/hover states in the side navigation.
- Added editorial title accents, calmer cards, stronger table headers, cleaner tabs and evidence-focused hover states.
- Added a dedicated `www/mfox_den.svg` Fox Den illustration.
- Added a pre-login Fox Den explanation: Review, Structure, Maintain.
- Updated the authenticated Fox Den hero to use the same dedicated illustration and clearer purpose statement.
- No invitation/join language was added to Fox Den.

## Runtime note
This build environment does not include R/Shiny, so the package received static checks but should still be opened once locally with `shiny::runApp()` for final visual inspection.
