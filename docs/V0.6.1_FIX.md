# MFOX v0.6.1 hotfix

This release fixes the malformed People & Labs server-code insertion in v0.6, where literal `\n` escape sequences were written into `app.R`. The block is now normal R source code.

`source("scripts/validate_database.R")` now also runs `parse(file = "app.R")`, so future validation checks both relational database integrity and Shiny application syntax.
