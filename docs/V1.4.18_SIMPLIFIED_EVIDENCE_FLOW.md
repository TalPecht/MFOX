# v1.4.18 — Simplified evidence flow

The Explore evidence Sankey was simplified from four visible layers to three:

**Sample type → Technology → Resource**

The prior `Curated studies` node is no longer shown. MFOX still uses study and assay identifiers internally to derive verified technology-to-resource relationships. Resource nodes remain Papers, Reusable datasets, Projects / programs, Institutions and Companies.

This is a visualization-only change; the underlying curated evidence and relationship tables are unchanged.
