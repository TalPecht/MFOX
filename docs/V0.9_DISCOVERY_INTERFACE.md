# MFOX v0.9 — Discovery interface

This release responds to usability feedback from v0.8.1.

## Scientific network
- Researcher co-authorship no longer uses a circular all-author layout.
- A deterministic force-directed layout focuses on the most recurrent researchers in the selected view.
- Users can control how many researchers are shown and can focus on Community-eligible researchers.
- Only the more connected researchers are labelled to reduce visual clutter.
- Clicking a researcher opens an in-app detail card with the person's profile link and their menstrual-fluid publications.

## Geography
Institution popups retain technology, sample, disease/question and research-domain context and now contain clickable researcher profile and publication links where URLs are curated.

## Landscape
The separate Gaps tab has been removed. Evidence coverage and zero cells are now integrated into Landscape. Landscape supports heatmap, bubble-matrix and stacked-bar views, with selectable row/column dimensions and stronger visual contrast.

## Plan a Study
The planner now combines matched evidence with a design/method snapshot, publication-linked researchers and reusable public datasets. It is a field-navigation and feasibility aid, not a protocol recommendation engine.

## Validation
The package was checked for balanced R delimiters and CSV primary/foreign-key integrity in the build environment. An R runtime was not available in the build environment; run `source("scripts/validate_database.R")` locally before launching.
