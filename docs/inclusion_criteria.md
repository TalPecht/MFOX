# Inclusion and exclusion criteria — working draft

## Include
- Human menstrual fluid, menstrual blood, menstrual effluent
- Direct cellular/tissue fractions
- Cell-free fractions
- Menstrual-fluid extracellular vesicles
- Menstrual-fluid-derived cultured cells (including MenSCs)
- Derived experimental materials when menstrual origin is explicit
- Molecular/high-dimensional profiling

## Exclude from the primary omics landscape
- Non-human studies
- Endometrial biopsy only, with no menstrual-fluid-derived material
- Conventional single-analyte studies unless embedded in a broader molecular profiling study
- Reviews/editorials as primary evidence records
- Unverifiable secondary mentions

Exact criteria should be frozen before the systematic search used for MFOX v1.0.
