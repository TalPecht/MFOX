# MFOX v1.0 — field resource redesign

## Purpose
v1.0 changes MFOX from a database-first dashboard into a reader-first field resource.

## Home
- Biological overview of menstrual fluid and its major study fractions.
- Reader-facing sample terminology while retaining the controlled ontology underneath.
- Overview of represented assay families and database metrics.
- Direct navigation into Landscape, Community, Study Planner and Data.

## Landscape
- Standalone Gaps section removed.
- One evidence engine supports Evidence matrix, Bubble matrix, Composition and Timeline views.
- All views use the same filtered evidence table.
- High-contrast evidence scale and reader-facing sample labels.
- Study table remains visible beneath the visualisation.

## Community
- Dense researcher hairball removed as the default navigation mechanism.
- Researcher directory plus institution/collaboration-group cards.
- Scientific connection maps focus on interpretable technology–disease, sample–technology and technology–domain relationships.
- Geography retains rich popups with researchers, technologies, samples, questions and linked publications.

## Plan a Study
- Expanded study-intelligence header: exact studies, assays, reported MF participants, public datasets, linked researchers and longitudinal studies.
- Exact evidence, adjacent evidence, methods, experts and reusable-data views.
- Adjacent evidence is descriptive similarity based on shared selected dimensions; it is not a recommendation or score of scientific value.

## Scope language
MFOX maps omics, molecular and cellular profiling of human menstrual fluid and its derivatives. Community is broader and publication-linked.
