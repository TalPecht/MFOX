# MFOX v1.1.2

## Home measurement-layer transparency
- Measurement-layer cards now distinguish **assay records** from **unique assay methods**.
- Hover/focus shows the exact assay methods represented and their record counts, generated live from `data/assays.csv`.
- Clicking a measurement layer opens **Explore** with the corresponding technology modalities selected.
- No method list or count is hard-coded.

## Discovery benchmark
Bister et al. (Science Immunology 2024; DOI 10.1126/sciimmunol.adj7168) is retained as a benchmark case for the planned repository-first discovery arm because NCBI BioProject PRJNA934582 explicitly records menstrual-blood collection while the PubMed title/abstract does not expose menstrual-fluid terminology.
