# MFOX v1.1.6 — Company expansion + contribution form fix

## Companies added
Added verified menstrual-fluid/menstrual-blood commercial/translational entities: NariNext, MenSC Labs, Fertilysis, Diamens and Papcup. These complement Qvin, NextGen Jane, theblood and Endometrics. Company coverage remains a curated, evolving census rather than a completeness claim.

## Contribution form fix
The form no longer silently stops when the menstrual-fluid description is blank. A submission now requires only a title/name OR identifier/URL. Missing required information produces a visible validation message. Successful writes produce a visible submission ID; write failures expose a visible error rather than appearing to do nothing.
