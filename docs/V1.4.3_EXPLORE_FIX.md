# MFOX v1.4.3 — Explore relational-link fix

## Fixed

A filtered Explore view could fail with `Error: [object Object]` in Evidence, Papers, Datasets and Projects & Programs while Labs/Companies still rendered.

The cause was an ambiguous `source_url` after joining project relationship tables to project/study entity tables. Both sides carry provenance URLs; dplyr therefore produced suffixed names, while downstream Explore code still referenced an unsuffixed `source_url`.

v1.4.3:

- renames project entity URLs to `project_source_url` before project joins;
- renames study entity URLs to `study_source_url` before study/project joins;
- preserves the relationship-table `source_url` as separate provenance;
- returns a typed empty project summary when the filtered studies have no project links;
- shows a readable Projects & Programs empty-state instead of constructing a broken join;
- applies the same explicit project URL naming to company↔project aggregation.
