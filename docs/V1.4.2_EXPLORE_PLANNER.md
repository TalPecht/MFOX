# MFOX v1.4.2 — Explore guidance + targeted Study Planner

## Product distinction

**Explore** is the field-discovery surface: it answers *what already exists?* Users can start from clinical context, technology or sample type and follow a consistent evidence subset across Evidence, Papers, Datasets, Projects & programs, and Labs & companies.

**Plan a Study** is the design-intelligence surface: it answers *for the study I am considering, what precedent can help me design it?* It requires at least one specific study feature before returning targeted precedent.

## Explore changes

- Added explicit `Any` to Clinical context, Technology and Sample type.
- `Any` is neutral in filtering; specific selections in the same dimension take precedence.
- `Reset to Any` returns all three dimensions to a neutral state and clears the public-dataset restriction.
- Added a prominent start guide inside **Curated studies and assays** when no specific filter is active.
- Added a distinct zero-result guide that explains how to broaden filters and that an empty intersection may represent a genuine evidence gap.
- Added a result-state banner for active matches.

## Planner changes

- Added explicit discovery-vs-planning explanations in both Explore and Plan a Study.
- Changed the planner action to **Build study intelligence**.
- All planner dimensions continue to allow `Any`, but at least one feature must be specific before a targeted evidence set is returned.
- Planner queries are captured when the user clicks the action button so results consistently reflect the submitted definition rather than unsaved dropdown changes.
