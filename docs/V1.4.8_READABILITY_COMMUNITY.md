# MFOX v1.4.8 — Readability + Community orientation

This release is a UI/readability update on v1.4.7. Scientific data and relational schema are unchanged.

## Changes
- Fox Den now uses logo option 3, retaining the menstrual-fluid droplet.
- Community gains an at-a-glance navigation layer that explains the purpose of each major view and links directly to its tab.
- Typography is enlarged across navigation, filters, tables, tabs, cards, helper text and planner controls.
- Home MFOX logo is larger.
- Desktop sidebar MFOX logo is larger, with matching sidebar/content offsets.
